# Module 7

- `M7.1`: 단일 프로세스 공개 릴리스 표면(`app/release/`)을 구성하는 코드다 — canned 기본값의 앱 조립(`app.py`), 롤링 분/일 한도 리미터(`limiter.py`), ingest 잠금·레이트리밋 미들웨어(`middleware.py`), 시크릿 리댁션(`secrets.py`), `DOCREVIEW_` 설정(`config.py`). `InProcessRateLimiter.check`의 분당 카운트 합산과 재시도 시각 탐색은 클라이언트당 deque 길이가 `rate_limit_per_day`(기본 `100`, 상한 `100_000`) 설정으로 이미 유계이고 독립 측정된 병목이 없어 현재 구조를 유지한다. LRU 축출(`max_clients`)과 `asyncio.Lock` 직렬화도 단일 워커 계약의 일부라 유지한다.
  - 완료 검수에서 실행 동작을 바꾸지 않는 정합성 수정 3건을 반영했다: `app/release/__init__.py` 패키지 docstring(D104)과 `SecurityHeadersMiddleware.__call__`·`ReleaseGuardMiddleware.dispatch` docstring(D102)을 [docstring.md](../docstring.md) 기준으로 추가, `create_release_app(services=...)` 어노테이션을 `ApiServices | None`에서 실사용 계약인 `RuntimeApiServices | None`으로 좁혀 `RuntimeDemoService`의 `M5Service` 프로토콜(`retrieve -> RetrievalResult`)과 정적으로 일치시켰고(basedpyright `0` 에러), `pyproject.toml` `[tool.pyright]` `exclude`에서 `tests/release`를 제거했다.
- `M7.2`: Hugging Face Spaces·컨테이너 릴리스 자산(`Dockerfile`, `docker-compose.yml`, `.dockerignore`, `deploy/huggingface/**`)을 정의하는 체크포인트다. Python 실행 핫패스가 없고 빌드 재현성과 시크릿 비포함이 계약이므로 성능 최적화를 적용하지 않는다.
- `M7.3`: 클린 체크아웃 검증 스크립트(`scripts/verify_clean_checkout.sh`)로 릴리스 게이트를 봉인하는 체크포인트다. 검증 절차 자체가 산출물이라 현재 구조를 유지한다.
