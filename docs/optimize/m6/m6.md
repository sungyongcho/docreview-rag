# Module 6

이 문서는 M6.2·M6.3 검수 결과다. M6.1 구현 변경은 [정직한 지원 판정과 안전한 Gradio 경계](m6-1.md)에 기록한다.

- `M6.2`: 포트폴리오 문서가 canned fixture, local runtime retrieval, local runtime review를 구분하고 architecture·evaluation·failure evidence를 연결하는 체크포인트다. 실행 핫패스가 없고 문서 동기화·언어 패리티·검증 가능한 주장 자체가 계약이므로 별도 성능 최적화를 적용하지 않는다.
- `M6.3`: M5의 실제 `RetrievalResult.hits`와 terminal `RunReport`를 M6 UI 결과에 결합하는 체크포인트다. query 후보는 미검토 상태로 구분하고 review citation과 별도 retrieval body의 identity를 fail-closed로 대조하며 M5 공개 반환 계약을 확장하지 않는다.
