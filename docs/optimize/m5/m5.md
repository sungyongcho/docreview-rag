# Module 5

이 문서는 M5.3 조립 검수 결과다. 상세 변경과 측정 근거는 [M5.1 공개 오류 계약](m5-1.md), [M5.2 runtime/CLI](m5-2.md), [M5.4 SSE](m5-4.md)에 기록한다.

- `M5.3`: HTTP와 CLI가 같은 evidence 공개 shape를 쓰고 runtime이 M2 retrieval·M4 workflow·secret-safe persistence를 주입 경계로 연결하는 체크포인트다. 별도 알고리즘 병목은 없고 request-owned session과 deterministic offline composition을 유지한다.
  - API cold import는 약 `1.4s`지만 대부분 M2/M4 public façade가 OpenAI·retrieval·DB 모델을 eager import하는 교차 모듈 비용이다. M5 파일의 dotted import만 바꾸면 Python이 package `__init__`을 먼저 실행하므로 효과가 없고, façade lazy화는 기존 re-export identity 계약을 바꾸는 넓은 작업이라 이번 패스에서 보류했다.
  - 기본 HTTP runtime은 deterministic embedding을 유지하고 LLM provider·budget 없이는 review를 typed 503으로 거부한다. 환경값만으로 유료 호출을 켜는 변경은 적용하지 않았다.
