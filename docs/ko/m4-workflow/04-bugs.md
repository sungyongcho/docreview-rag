# M4 버그

이 파일은 구현 과정의 함정과 각각에 대한 좁은 범위의 수정 방법을 기록합니다. 추측에 근거한 향후 기능 목록이 아닙니다.

## B01 — 없는 그래프 라이브러리를 암묵적인 선택 경로로 취급

**증상:** 잠금 파일과 런타임에는 해당 모듈이 없는데 로컬 코드 예제가 LangGraph를 전제로 합니다.

**근본 원인:** 의존성 호환성을 확인하기 전에 아키텍처 설명에서 프레임워크를 지정했습니다.

**수정:** 타입이 적용된 결정론적 러너 하나를 사용하고 누락된 프레임워크 기능 범위를 문서화합니다. 이후 마일스톤에서 해당 의존성의 필요성이 입증되더라도 순수 노드 함수가 마이그레이션 경계로 유지됩니다.

**회귀 검사:**

```bash
uv run python -c 'import importlib.util; assert importlib.util.find_spec("langgraph") is None'
```

## B02 — 구문상 유효한 인용을 신뢰함

**증상:** 양의 정수는 스키마상 유효하므로 엄격한 `AnswerDecision`도 청크 `999`를 인용할 수 있습니다.

**근본 원인:** JSON 검증은 형태를 보장할 뿐, 검색된 증거에 속하는지는 보장하지 않습니다.

**수정:** 인용과 평가를 통과한 청크 ID의 교집합을 구하고, 제거된 ID를 기록하며, 교집합이 비어 있으면 지원 답변의 등급을 낮춥니다.

**회귀 검사:**

```bash
uv run pytest -o addopts="" tests/workflow/test_04_nodes.py -k "citation" -q
uv run pytest -o addopts="" tests/workflow/test_05_runner.py -k "fabricated" -q
```

## B03 — 누락된 평가를 아무런 표시 없이 통과시킴

**증상:** 평가기가 여러 청크가 포함된 프롬프트에 유효한 평가 하나만 반환하고, 누락된 청크는 결정 이력에서 사라집니다.

**근본 원인:** `RelevanceJudgment`는 ID의 고유성을 보장하지만 예상 집합은 알 수 없습니다.

**수정:** 반환된 ID를 제공된 증거 ID와 비교합니다. 알 수 없는 ID는 `GradeReferencesFiltered`를 생성하고, 누락된 ID는 `GradeCoverageIncomplete`를 생성하며 관련 없음으로 계산합니다.

**회귀 검사:**

```bash
uv run pytest -o addopts="" tests/workflow/test_04_nodes.py -k "coverage" -q
```

## B04 — 공급자를 호출할 때마다 워크플로 예산을 초기화함

**증상:** 평가와 검사가 각각의 제한은 통과하지만 합계가 실행 제한을 초과합니다.

**근본 원인:** 공급자 예산과 워크플로 예산은 서로 다른 경계를 해결합니다. 원래 공급자 허용량을 재사용하면 이전 추적을 무시하게 됩니다.

**수정:** 노드 실행 전 가드는 누적 추적을 읽으며, 각 공급자 호출에는 이전 토큰 및 예상 비용 사용량을 차감한 허용량을 전달합니다.

**회귀 검사:**

```bash
uv run pytest -o addopts="" tests/workflow/test_05_runner.py -k "cumulative" -q
```

## B05 — 인용된 청크 내부를 잘라냄

**증상:** 프롬프트에는 본문 조각이 들어 있지만 최종 인용은 저장된 전체 범위를 가리킵니다.

**근본 원인:** 문자 예산 코드가 증거 단위를 선택하지 않고 문자열을 자릅니다.

**수정:** 각각의 완전한 `index_text` 값을 유지하거나 제외합니다. 제외된 모든 청크 ID를 기록하고 인위적인 부분 인용을 절대 만들지 않습니다.

**회귀 검사:**

```bash
uv run pytest -o addopts="" tests/workflow/test_04_nodes.py -k "context_limit" -q
```

## B06 — 공급자 실패를 포착하지만 원시 출력을 잃음

**증상:** 실행 결과가 `schema_rejected`이지만 검사할 수 있는 모델 출력이나 재시도 횟수가 없습니다.

**근본 원인:** 워크플로가 파싱된 데이터만 매핑하고 실패 시 공급자 메타데이터를 버립니다.

**수정:** 노드 전이를 적용하기 전에 모든 공급자 결과를 `StepTrace`로 변환합니다. 최종 보고서는 추적 튜플과 타입이 지정된 거부를 유지합니다.

**회귀 검사:**

```bash
uv run pytest -o addopts="" tests/workflow/test_05_runner.py -k "schema_rejection" -q
```

## B07 — 일반 인수 검사 중 유료 테스트를 호출함

**증상:** 키를 구성한 개발자가 일반 테스트 스위트를 실행하여 의도하지 않은 요청 비용이 발생합니다.

**근본 원인:** 자격 증명이 있다는 사실만으로 동의했다고 간주합니다.

**수정:** 실제 테스트에는 `RUN_OPENAI_WORKFLOW_LIVE=1`, 명시적 모델, 키가 필요합니다. 일반적인 결정론적 인수 검사에서는 어느 것도 제공하지 않습니다.
