# 구조

DocReview는 SEC와 DART 공시를 원문을 보존하는 하나의 처리 경로로 준비합니다. [Quick Start — DEV ONLY](quickstart-dev.md)에서 첫 보고서 두 개를 준비하고, [검색 테스트](retrieval.md)로 근거를 확인한 뒤 [첫 답변](answers.md)으로 이어갑니다.

## 공통 코퍼스 계약 {#contracts}

`schemas/manifest.schema.json`은 Python `Manifest` 계약에서 생성합니다. 코퍼스에는 다음 정보가 구분되어 있습니다.

- **코퍼스 식별 정보:** 로컬 디렉터리와 독립된 식별자와 표시 이름입니다.
- **공시 참조:** 공통 공시 식별자·날짜·언어·회사 별칭과 명시적인 SEC 또는 DART 메타데이터입니다.
- **원문 artifact:** 코퍼스 기준 상대 경로·원본 바이트 해시·인코딩·수집 출처입니다. DART 압축 파일과 변환된 텍스트는 서로 다른 artifact입니다.
- **처리 선택:** 처리할 원문 artifact를 정확히 지정하는 이름 있는 선택입니다. 문서 목록을 복사하지 않습니다.

원문은 경로가 코퍼스 안에 있는지와 실제 바이트가 해시에 일치하는지 확인한 뒤 해독합니다. 수집 시각을 모르면 파일 수정 시각으로 추측하지 않고 알 수 없는 값으로 기록합니다.

## 공통 처리 {#processing}

두 어댑터는 같은 원문 연결 구조를 반환합니다. 공통 처리는 제목·문단·표·셀·행과 열의 범위·단위를 보존합니다. 작은 표는 그대로 유지하고, 큰 표는 제목과 단위를 반복하는 행 묶음으로 나눕니다. 너무 긴 행은 셀 경계에서, 너무 긴 서술형 셀은 문장 경계에서 나눕니다.

**문맥과 본문을 합쳐** 2,048토큰을 목표로 합니다. 최대 8,192토큰과 기본 근거 예산에 맞춘 12,000자 제한을 적용합니다. 입력 한도가 더 작은 모델은 해당 모델의 실제 토크나이저와 더 작은 한도를 사용합니다. 올바른 경계에서 나눠도 들어가지 않는 내용은 명시적인 오류로 알려줍니다.

각 조각은 실제 원문 범위, 원본 헤더 셀, 연결된 단위·기준일의 별도 원문 범위를 보존합니다. 정규화된 셀 텍스트의 위치를 HTML 원문 위치인 것처럼 표시하지 않습니다. 표 조각은 각각 독립된 검색 단위입니다.

## 저장과 식별 {#storage}

| 개체 | 역할 |
|---|---|
| 코퍼스·처리 선택 | 작업에서 처리할 원문을 지정합니다 |
| 문서 | 정규화된 공시 식별 정보를 저장합니다 |
| 원문 artifact | 수집한 바이트와 출처를 식별합니다 |
| 파싱 구조·현재 파싱 참조 | 공시 식별 정보와 구조 분석 결과를 구분합니다 |
| 청크 | 원문 근거·문맥·조각 메타데이터·안정적인 식별자를 저장합니다 |
| 임베딩 | 정확한 입력과 공급자·모델·차원·토크나이저를 벡터에 연결합니다 |
| 키워드 통계 | PostgreSQL 키워드 검색과 BM25를 지원합니다 |
| 작업 | 대기·진행·취소·재시도·중단 상태를 기록합니다 |
| 평가·스냅샷 | 측정 결과와 변경되지 않는 인덱스 근거를 보존합니다 |
| 실행·트레이스 | 답변 실행 과정·사용량·실패를 설명합니다 |

표시 순서는 청크의 식별자가 아닙니다. 내용이 같은 청크의 순서를 바꿔도 DB 식별자와 재사용할 수 있는 벡터가 유지됩니다. 임베딩 응답을 저장할 때는 현재 입력이 호출 전과 같은지 다시 확인합니다.

스냅샷은 실제 평가한 인덱스의 fingerprint를 비교하고, 하나의 repeatable-read transaction에서 상태를 복사합니다. 이후 실시간 인덱스가 바뀌어도 저장된 스냅샷은 바뀌지 않습니다.

## CLI·웹·실행 {#execution}

CLI와 웹은 같은 준비 작업을 요청합니다. 웹의 통신 타입은 API 스키마에서 생성합니다. 작업 상태는 `queued`, `running`, `succeeded`, `failed`, `cancelled`, `interrupted`이며, 작업이 끝나면 준비 상태가 자동으로 갱신됩니다.

DEV는 `OPENAI_API_KEY_LOCAL`만, production은 `OPENAI_API_KEY_PROD`만 읽습니다. 브라우저 대화·수집 원문·서버 인덱스는 서로 다른 저장소입니다. 일반 설치는 호환되는 데이터를 보존하고, [전체 초기화](cli.md#종료와-선택적-데이터-삭제)는 별도 작업으로 실행합니다.
