# Meridian Code Academy — Cookie Declaration

This declaration explains how MCA uses cookies on its websites. Sample content for a
document-review demo.

## 1. What a Cookie Is

A cookie is a small text file stored on a visitor's device while browsing MCA sites. It lets
the issuer recognize the device during its validity period.

## 2. Retention

Audience cookies are stored for at most 13 months. Data collected through cookies is retained
for at most 25 months. These periods match the Privacy & Data Retention Policy.

## 3. Purposes

### 3.1 Audience statistics
MCA uses analytics cookies to measure traffic and improve site performance. Data shared with
the analytics provider is anonymized.

### 3.2 Remembering choices
A cookie records the visitor's cookie preferences so they are not asked again on each visit.

## 4. Managing Preferences

Audience cookies are never set without consent. Visitors can enable or disable them at any
time through the "Cookie policy" control on the site.

## 5. Updates

This declaration may be updated; the latest version is always published on the MCA sites.
