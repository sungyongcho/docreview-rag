# Meridian Code Academy — IT & Security Project Charter

This Charter governs the use of MCA computing resources and the conduct of security
projects. Sample content for a document-review demo.

## 1. General Use

MCA computing resources are for educational use only. Students must respect the
confidentiality of others' information and third-party intellectual-property rights, and may
circulate only lawful content on the network.

## 2. Security Projects

### 2.1 Authorized targets
Actions may be carried out only against targets explicitly named in the project subject. Any
action against a target not listed is a Tier 3 offense under the Internal Rules.

### 2.2 Time windows
Where the subject sets start and end dates, no action may be taken against the target outside
those dates.

### 2.3 Containment
Actions must be contained, for example by running in an isolated virtual machine. If a
required pre-check fails, the action must not proceed.

### 2.4 Destructive code
Writing, storing, or distributing destructive code is forbidden. Intent to cause harm need
not be shown for this rule to apply.

## 3. Vulnerability Disclosure

Public disclosure of a vulnerability requires MCA approval. "Public" means any audience
beyond the participants in the project subject to this Charter.

## 4. Network

Connecting to a reserved or forbidden workstation, or to a wired network socket, without
authorization from MCA staff is prohibited.
