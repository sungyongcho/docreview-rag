# M1.4 검증

## 필수 명령

집중 테스트 실행:

```bash
uv run pytest tests/db -q
```

파일을 변경하지 않고 범위 지정 린트 실행:

```bash
uv run ruff check --no-fix app/db/models.py app/ingestion/seed.py tests/db
```

집중형 테스트 명령에는 데이터베이스가 필요하지 않다. PostgreSQL을 사용할 수 없으면 `test_05_postgres.py`는 짧은 탐색 뒤 건너뛰고, 연결할 수 있으면 자동으로 활성화된다.

## 테스트 대응표

| 테스트 파일 | 증거 |
|---|---|
| `test_01_models.py` | 문서 메타데이터, 파서/Item 상태 JSON, 소스 식별 정보, 증거/문맥 분리, 생성된 TSV, null 허용 임베딩, 제약 조건 |
| `test_02_records.py` | 결정론적 변환, 상태 보존, 안전하게 실패하는 출처 추적 검증 |
| `test_03_upserts.py` | PostgreSQL 충돌 대상, 임베딩 삽입 없음, 조건부 무효화, 배치, 커밋, 롤백 |
| `test_04_corpus.py` | 공시(20) 전체, 현재 M1.3 청크 전체, 표 종류, 소스 해시와 구간 |
| `test_05_postgres.py` | 선택적 임시 테이블 재실행, 안정적인 개수, 임베딩 보존과 무효화 |

## 완료 단언

- [x] `documents.doc_id`는 문서 충돌 키다.
- [x] `(chunks.doc_id, chunks.ordinal)`은 청크 충돌 키다.
- [x] 문서 메타데이터에는 보고 기간, 소스 길이, 소스 SHA-256 값이 포함된다.
- [x] 문서 메타데이터는 파서 상태와 xref Item 상태/참조 증거를 보존한다.
- [x] 청크 행은 본문, 문맥 헤더, 인덱스 텍스트, 종류, Item, ordinal, 인용, 소스 구간, 소스 SHA-256 값을 저장한다.
- [x] PostgreSQL은 `content_tsv`를 `index_text`에서 계산한다.
- [x] M1.4 레코드와 삽입 값은 임베딩을 제외한다.
- [x] 같은 인덱스 텍스트는 기존 M2 임베딩을 보존한다.
- [x] 변경된 인덱스 텍스트는 저장된 임베딩을 `NULL`로 무효화한다.
- [x] 전체 준비가 데이터베이스 트랜잭션보다 먼저 수행된다.
- [x] 명시적 트랜잭션 하나가 모든 코퍼스 쓰기와 오래된 행 삭제를 소유한다.
- [x] 동일하게 재실행해도 행을 추가하지 않는다.
- [x] 현재 청크 집합이 더 짧아져도 후행 행을 남기지 않는다.
- [x] 테스트는 정규 `app/ingestion/seed.py` 경로를 직접 채점한다.

## 코퍼스 골든 출처

`tests/db/golden.py`는 `tests/chunk/golden.py`에서 문서 식별 정보와 집계 개수를 산출한다. 따라서 M1.3 단계와 M1.4 단계가 서로 충돌하는 청크 합계를 게시하지 못한다. `test_04_corpus.py`는 집계값뿐 아니라 문서별·종류별 준비된 레코드를 검사한다.

현재 예상 기준선:

```text
documents = 20
chunks = 9172
text chunks = 8083
table chunks = 1089
```

검토된 M1.3 청크 계약이 바뀌면 먼저 해당 골든 파일을 업데이트한다. 그러면 M1.4 단계가 새로운 전체 집합이 일대일로 영속화됨을 증명한다.

## 수동 데이터베이스 감사

의도한 애플리케이션 데이터베이스에 시드를 실행한 뒤 개수와 null 임베딩을 검사한다.

```sql
SELECT count(*) FROM documents;
SELECT kind, count(*) FROM chunks GROUP BY kind ORDER BY kind;
SELECT count(*) FROM chunks WHERE embedding IS NOT NULL;
```

고정 코퍼스에서 첫 번째 결과는 (20)이어야 한다. `text`와 `table`이 모두 있어야 한다. M2를 실행하기 전 마지막 결과는 영이어야 한다.

동일한 시드 명령을 다시 실행하고 개수 쿼리를 반복한다. 개수는 바뀌지 않아야 한다.

## 실패 분류

| 실패 | 유력한 담당 영역 |
|---|---|
| SQL 이전의 매니페스트 개수 또는 메타데이터 오류 | 코퍼스 매니페스트 또는 M1.1 파서 입력 |
| 구간/해시/본문 변환 오류 | M1.3 청크 계약 또는 교체된 소스 스냅샷 |
| 충돌 SQL 컴파일 오류 | M1.4 L2 명령문 작성 |
| 일부 쓰기 또는 중첩 세션 오류 | M1.4 L3 트랜잭션 호출자 |
| PostgreSQL 테스트 건너뜀 | 로컬 데이터베이스 가용성 문제이며 단위 테스트 실패가 아님 |
| 기존의 null이 아닌 임베딩이 null로 변경 | `index_text`가 바뀌면 예상되는 동작이며 M2가 다시 생성해야 함 |
