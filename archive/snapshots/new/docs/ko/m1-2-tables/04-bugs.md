# M1.2 버그

## B01. colspan 텍스트를 모든 칸에 복제

**증상:** 숫자와 레이블이 병합 폭만큼 반복돼 검색 텍스트가 오염됐다. **원인:** 밀집 격자의 모든 점유 칸에 원래 셀 텍스트를 복사했다. **수정:** 좌상단에만 텍스트를 두고 나머지는 빈 문자열로 점유한다. **회귀 테스트:** `test_rowspan_carries_down_without_duplicating_text`, `test_colspan_keeps_text_in_first_cell_only`.

## B02. 원시 행 길이를 그대로 신뢰

**증상:** 비정형 표에서 L3 열 스캔이 `IndexError`로 실패했다. **원인:** 선언된 행 폭이 서로 다른 SEC 조판을 직사각형 데이터로 가정했다. **수정:** 전체 점유 좌표의 최대 너비에 맞춰 모든 격자 행을 채운다. **회귀 테스트:** `test_grid_is_rectangular`.

## B03. `<th>`를 헤더 조건으로 사용

**증상:** 모든 표가 헤더 없는 본문으로 처리됐다. **원인:** 코퍼스 전체에 `<th>`가 0개인데 일반 웹 표 가정을 적용했다. **수정:** 선두 행의 형태로 헤더를 추론하고 불확실하면 `([], grid)`를 반환한다. **회귀 테스트:** 헤더 테스트 3종.

## B04. 표 마크다운을 `Block.text`에 저장

**증상:** 파서 커버리지 골든값 20개가 전부 이동했다. **원인:** M1.1의 소스 가시 텍스트 지표와 M1.2 검색 렌더링을 한 필드에 섞었다. **수정:** `tables.py`를 HTML 순수 함수로 두고 M1.3이 필요할 때 호출한다. **회귀 테스트:** 기존 M1.1 스위트 전체 + M1.2 진입점 테스트.

## B05. 수집 단계에서 괄호음수를 음수 기호로 변경

**증상:** 마크다운 숫자가 공시 원문 표기와 달라졌다. **원인:** 검색 편의를 인용 충실도보다 우선했다. **수정:** 괄호 표기를 그대로 보존하고 쿼리 측 정규화로 미룬다. **회귀 테스트:** `test_parenthesized_negatives_survive_verbatim`.

## B06. 대표 골든이 첫 5줄만 검사했다

**증상:** `Operating expenses` 이후 행이 사라져도 대표 테스트가 통과할 수 있었다. **원인:** 전체 예상 문자열에 `startswith()`를 사용했다. **수정:** 마지막 `Net income` 행까지 예상값에 넣고 동등성으로 비교한다. **회귀 테스트:** `test_income_statement_renders_as_expected`.

## B07. L3와 L4 측정값을 하나로 기록했다

**증상:** 문서는 L3가 만든 셀이 66,575 이라고 했지만 실제 L3는 69,241였다. **원인:** 최종 축소만 측정하고 중간 단계를 저장하지 않았다. **수정:** 측정 스크립트가 전개, 빈 축 제거, 단위 병합 이후의 개수를 각각 출력한다. **회귀 도구:** `scripts/measure_tables.py`.

## B08. 셀 안의 파이프가 새 열을 생성

**증상:** 마크다운 행 너비가 달라져 렌더링이 깨졌다. **원인:** 셀 텍스트의 `|`를 그대로 직렬화했다. **수정:** `\|`로 이스케이프한 뒤 행을 만든다. **회귀 테스트:** `test_cell_pipes_are_escaped`, `test_markdown_rows_all_have_the_same_width`.
