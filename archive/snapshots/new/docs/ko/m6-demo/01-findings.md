# M6 실측

이 결과는 2026-08-12 기준으로 기록된 저장소 상태와 로컬 인수 증거에 근거합니다. M6.1, M6.2 및 M6.3 통합 결합이 완료되었습니다.

## F1 — 선택적 Gradio 표면은 잠겨 있고 실행할 수 있습니다

프로젝트는 `demo` 선택적 의존성을 선언하며, 잠금 파일은 Gradio를 해석합니다. 잠긴 추가 의존성 동기화에서는 변경 사항이 없다고 보고되었습니다. 집중 데모 스위트는 `6 passed`를 출력했고, `build_demo()`는 UI를 구성했으며, 실제 루프백 실행은 서버가 정상적으로 종료되기 전에 `http://127.0.0.1:7861/`을 반환했습니다.

이는 M6.1 단계를 로컬에서 실행할 수 있음을 입증합니다. 데이터베이스 연결, 런타임 기반 검색 또는 공개 호스팅을 입증하지는 않습니다.

## F2 — 기본 데모는 의도적으로 미리 준비된 데이터를 사용합니다

서비스를 주입하지 않으면 `build_demo()`는 `CannedDemoService`를 선택합니다. 지원되는 분기에서는 Acme 인용, 범위, 해시, 청크 ID, 본문과 비용 없는 추적을 반환합니다. 지원되지 않는 분기에서는 증거 없이 `retrieval_empty`를 반환합니다.

공시 자료 20 건이 AMD, INTC, MU, NVDA에 동일하게 나뉘어 있는 커밋된 매니페스트에는 Acme가 없습니다. 따라서 미리 준비된 값은 합성 UI 픽스처입니다. 이로써 포트폴리오에 결정론적 오프라인 경로를 제공하는 대신 엄격한 표기 의무가 생깁니다.

## F3 — 런타임 어댑터는 M5 접점을 보존합니다

집중 테스트는 `RuntimeDemoService`가 주입된 M5 서비스를 통해 위임하고, 타입이 지정된 필터를 전달하며, 반환된 청크를 공개 증거로 변환하고, 타입이 지정된 `ApiProblemError`를 비밀이 없는 실패 상태로 매핑함을 입증합니다. UI를 구축하는 동안 자격 증명을 찾거나 서비스를 열지 않습니다.

M6.3 단계에서는 구체적인 반환 형태의 간극을 해소했습니다. `RuntimeDemoService`는 `RetrievalResult.hits`를 읽으며 이는 `RuntimeApiServices.retrieve()`와 일치합니다. 집중 통합 회귀는 실제 도메인 반환 타입을 구성하고 `results` 속성이 없음을 확인합니다. 기본 실행기는 여전히 미리 준비된 모드를 선택하며, 런타임 표기는 명시적으로 서비스를 주입한 경우에만 사용할 수 있습니다.

## F4 — 프로젝트의 가장 강력한 증거는 원문 계보입니다

수집과 검색 경계에서는 문서 ID, 사람이 읽을 수 있는 인용, 원본 소스 범위, 소스 SHA-256, 청크 종류, 청크 ID를 보존합니다. M4는 검색되고 등급이 매겨진 ID를 기준으로 모델 인용을 필터링합니다. M5는 CLI와 HTTP를 통해 같은 정체성을 투영합니다.

이는 계층 전반에서 결정론적이고 실행 가능하므로 단순한 답변 유창성보다 강력한 포트폴리오 주장입니다.

## F5 — 평가 품질은 낮고 결과가 엇갈립니다

원문에 결속된 골든 스위트는 에이전트가 선별한 사례 28건, 즉 긍정 사례 24건과 부재 사례 4 건으로 구성됩니다. 두 청크 구성과 세 검색 전략을 조합한 결정론적 실험에서 다음과 같이 측정했습니다.

| 청크 목표 | 최고 Recall@5 | 최고 MRR | 가장 빠른 전략 P95 |
|---:|---:|---:|---:|
| 500 | 0.125 | 0.070833 | 5.644 ms 어휘 검색, 적중 없음 |
| 1200 | 0.062500 | 0.083333 | 8.151 ms 어휘 검색, 적중 없음 |

어휘 검색은 후보를 하나도 반환하지 않았으므로 하이브리드 품질은 벡터 품질과 같았고 지연 시간만 늘었습니다. 이 실험은 평가 배관과 지연 시간 예산을 검증하지만, 프로덕션 검색 방식의 선택을 뒷받침하지는 않습니다.

## F6 — 성능 예산을 통과했습니다

격리된 결정론적 실행에서는 청크 12,984건을 500자 실험군에 75.158초 만에, 청크 9,172건을 1200자 실험군에 63.881초 만에 인덱싱했습니다. 둘 다 300초 미만이었습니다. 고정된 쿼리 200 건의 1200-하이브리드 측정은 12.994 초가 걸렸고 P95는 71.480 ms로 90초 미만이었습니다.

이는 로컬 환경에서 측정한 값이며, 호스팅된 서비스의 지연 시간을 보장하지 않습니다.

## F7 — M6 이후 회귀 통과 수는 측정값입니다

M6 이후 전체 스위트 결과는 `697 passed, 1 skipped`였습니다. 건너뛴 항목은 명시적으로 옵트인해야 하는 실제 OpenAI 워크플로 테스트입니다. 이 값은 런타임 결합 이후 전체를 다시 실행하여 얻었으며, 데모 테스트 6개를 이전 값 `691`에 더한 결과가 아닙니다.

## F8 — 현재 증거 가치가 있는 스크린샷은 없습니다

M6에 커밋된 이미지 아티팩트는 없습니다. 텍스트 자리표시자는 의도적으로 해당 사실을 명시합니다. 이로써 오래되었거나 미리 준비된 캡처를 런타임 통합의 증거로 제시하는 일을 방지합니다. 향후 스크린샷은 선택적 증거이며, 모드를 표시하고 통과한 리비전과 일치해야 합니다.
