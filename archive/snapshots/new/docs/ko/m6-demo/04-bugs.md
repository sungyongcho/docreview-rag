# M6 버그

다음은 범위를 좁힌 회귀 방지 장치가 있는 구체적인 포트폴리오 및 데모 실패 유형입니다.

## B01 — 합성 Acme 증거를 말뭉치 결과로 제시

**증상:** README, 스크린샷 또는 녹화에서 기본 Gradio 답변을 SEC 검색 증거로 설명합니다.

**근본 원인:** `CannedDemoService`는 서비스 없이 UI를 테스트할 수 있도록 의도적으로 사실적으로 보이지만, 이 서비스의 Acme 공시 자료는 커밋된 매니페스트에 없습니다.

**수정:** 기본 실행에 `canned fixture`라고 표시하고, 명시적으로 주입된 런타임 서비스에만 로컬 런타임 표기를 사용합니다.

**회귀 검사:**

```bash
uv run pytest -o addopts="" tests/demo -k "canned_mode" -q
```

## B02 — UI 실행과 런타임 통합을 혼동

**증상:** 루프백 URL이 성공적으로 열렸다는 이유로 마일스톤이 엔드투엔드라고 선언합니다.

**근본 원인:** UI 구성과 소켓 실행만으로는 어떤 서비스가 주입되었는지 입증할 수 없습니다.

**수정:** 루프백 실행 증거와 실제 반환 타입 통합 증거를 분리해 유지합니다. 런타임 녹화에는 화면에 보이는 모드 표기와 커밋된 말뭉치의 증거를 요구합니다.

**회귀 검사:**

```bash
uv run pytest -o addopts="" tests/demo -k "runtime_adapter" -q
```

## B03 — 잠금 파일 밖에서 Gradio 설치

**증상:** 한 컴퓨터에서는 데모가 작동하지만 깨끗한 설정에서는 선택적 의존성이 없거나 다르게 해석됩니다.

**근본 원인:** 패키지를 직접 설치하면 프로젝트의 추가 의존성과 잠금 파일을 우회합니다.

**수정:** 선택적 `demo` 추가 의존성을 선언하고 `uv.lock`에 유지하며 잠긴 동기화를 사용합니다.

**회귀 검사:**

```bash
uv sync --locked --extra demo --dry-run
```

## B04 — 추적 정보 표시에 자격 증명 유출

**증상:** UI 상태 또는 렌더링된 오류에 `api_key`, `secret` 또는 인증 값이 포함됩니다.

**근본 원인:** 원시 설정이나 임의 예외 객체를 Gradio에 전달합니다.

**수정:** 타입이 지정된 `DemoTrace` 필드와 정제된 타입 서비스 오류만 렌더링합니다. 브라우저에서 공급자 키를 받지 마십시오.

**회귀 검사:**

```bash
uv run pytest -o addopts="" tests/demo -k "secret or fail_closed" -q
```

## B05 — 이전 통과 수를 산술 계산으로 변환

**증상:** 문서에 697건 통과를 보고합니다. 이는 M6.1 단계에서 테스트 6개를 이전 691건 통과 실행에 추가했기 때문입니다.

**근본 원인:** 하나의 전체 스위트에서 측정하지 않고 테스트 합계를 더했습니다.

**수정:** `691 passed, 1 skipped`는 날짜가 기록된 M5.3 이전 체크포인트로만 유지합니다. M6 이후 스위트는 다시 실행하여 `697 passed, 1 skipped`를 측정했습니다.

**회귀 검사:**

```bash
uv run pytest -o addopts="" -q
```

## B06 — 스크린샷 자리표시자를 증거로 사용

**증상:** 깨진 이미지, 모의 프레임 또는 TODO 자리표시자가 별도 설명 없이 증거 제목 아래에 표시됩니다.

**근본 원인:** 포트폴리오 레이아웃 작업이 검증된 통합보다 앞서 나갑니다.

**수정:** 증거가 아니라고 명시하는 텍스트 전용 자리표시자를 사용합니다. 향후 모든 이미지는 테스트를 통과한 리비전에 해당해야 하며 데모 모드를 표시해야 합니다.

**회귀 검사:**

```bash
rg -n "placeholder|canned fixture|runtime" README.md docs/en/m6-demo docs/ko/m6-demo
```

## B07 — 복사한 소스 또는 링크가 서로 어긋남

**증상:** 튜토리얼 코드가 `app/demo.py`와 다르거나 인덱스가 존재하지 않는 파일 또는 제목을 가리킵니다.

**근본 원인:** 포트폴리오 편집을 설명문만 다루는 작업으로 취급하여 저장소 동기화를 건너뜁니다.

**수정:** 렌더링 예제에 소스 앵커를 지정하고 루트 README, 문서 트리, 모듈 경로 전체에 문서 검사기를 실행합니다.

**회귀 검사:**

```bash
uv run python scripts/check_doc_code.py README.md docs deploy/huggingface/README.md
```

## B08 — M5 도메인 결과 대신 가짜 반환 형태를 테스트

**증상:** 집중 런타임 어댑터 테스트는 통과하지만 실제로 주입된 `RuntimeApiServices` 결과를 증거로 변환하는 중 실패합니다.

**과거의 근본 원인:** 데모 어댑터는 `retrieval.results`를 읽었지만 M5는 `RetrievalResult.hits`를 반환했고, 집중 테스트의 가짜 객체에는 `results` 속성이 있었습니다.

**수정:** 이제 어댑터는 `RetrievalResult.hits`를 읽습니다. 회귀 테스트는 해당 실제 반환 타입을 구성하고 가짜 `results` 속성이 없다고 단언합니다.

**회귀 검사:**

```bash
uv run pytest -o addopts="" tests/demo tests/api/test_08_integration.py -q
```
